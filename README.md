# AI Productivity Bot

Telegram-бот для управления продуктивностью, построенный по принципам модульной архитектуры. Бот объединяет в себе менеджер задач, трекер привычек, Pomodoro-таймер и интеллектуального ассистента на базе Google Gemini.

## 🛠 Архитектура проекта

Проект реализован с использованием **многослойной архитектуры (Layered Architecture)**, что обеспечивает высокую масштабируемость и легкость поддержки.

### Структура слоев:
1.  **Interface Layer (`handlers/`)**: Обрабатывает входящие сообщения от Telegram, управляет состояниями диалогов (`ConversationHandler`) и формирует ответы.
2.  **Service Layer (`services.py`)**: Содержит всю бизнес-логику приложения. Сервисы изолированы от интерфейса и работают с данными, обеспечивая валидацию и обработку ошибок.
3.  **Data Access Layer (`db.py`)**: Низкоуровневая работа с базой данных SQLite.
4.  **Intelligence Layer (`nlp.py`)**: Гибридная система разбора намерений (Regex + LLM) для поддержки свободного ввода.
5.  **Utility Layer (`utils/`)**: Общие инструменты, управление клавиатурами и система кастомных исключений.

## 🌟 Основные возможности

- **Умные задачи**: Создание дел с дедлайнами и категориями. Поддержка естественного языка («завтра в 10 утра купить хлеб»).
- **Трекер привычек**: Система отслеживания серий (streaks) с гибкой настройкой периодичности.
- **Pomodoro**: Интегрированный таймер фокусировки с привязкой к конкретным задачам.
- **AI-Ассистент**: Интеграция с Google Gemini для анализа продуктивности и советов по тайм-менеджменту.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Конфигурация
Создайте файл `.env` на основе `.env.example`:
- `TELEGRAM_BOT_TOKEN`: Токен от @BotFather.
- `GEMINI_API_KEY`: Ключ из Google AI Studio.

### 3. Запуск
```bash
python bot.py
```

## 📈 Технический стек
- **Язык**: Python 3.10+
- **Библиотека**: `python-telegram-bot` (Asyncio)
- **БД**: SQLite3
- **AI**: Google Gemini API / DeepSeek API
- **Паттерны**: Service Layer, Singleton (DB connection), State Machine.
